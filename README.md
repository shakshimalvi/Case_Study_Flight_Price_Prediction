# Case_Study_Flight_Price_Prediction
## 📌 Project Overview

This project aims to **predict airline ticket prices ** based on historical flight data. Flight prices vary depending on multiple factors such as airline, source, destination, number of stops, duration, and departure time.

The goal of this project is to analyze these factors and build a model that can **estimate flight prices accurately**. The project demonstrates a complete **end-to-end data science workflow**, including data preprocessing, exploratory data analysis, feature engineering, and machine learning model development.

---

## 📊 Dataset

The dataset contains information about different flights, including:

* Airline
* Source city
* Destination city
* Date of journey
* Departure time
* Arrival time
* Duration of flight
* Total number of stops
* Additional flight information
* Ticket price (target variable)

## ⚙️ Project Workflow

1. **Data Collection**
   Loaded the flight dataset and examined its structure.

2. **Data Preprocessing**

   * Handled missing values
   * Converted categorical data into numerical format
   * Extracted useful features from date and time columns

3. **Exploratory Data Analysis (EDA)**

   * Visualized relationships between features and ticket prices
   * Identified important factors affecting price variations

4. **Feature Engineering**

   * Created new variables such as journey day, month, and duration features
   * Applied encoding techniques for categorical variables
